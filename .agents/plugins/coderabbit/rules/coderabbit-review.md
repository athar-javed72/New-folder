# CodeRabbit Review & Quality Protocols

1. **Security-First**: Never let hardcoded secrets, unprotected endpoints, or unvalidated inputs pass review.
2. **No False Confidence**: If an issue or edge case is suspected, flag it with actionable explanations.
3. **Verification Before Merge**: All critical and major issues identified during CodeRabbit review must be fixed and validated before a phase is marked complete.
